# What Is Artificial Intelligence?

Artificial intelligence, or AI, is software designed to do tasks that usually need some human intelligence. These tasks can include understanding words, recognizing pictures, making suggestions, or finding patterns in information.

Some AI systems learn patterns from examples. For example, after seeing many labeled pictures of cats and dogs, a system can learn to sort new pictures. It uses patterns in the examples; it does not learn exactly like a person.

AI is useful in tools such as voice assistants, translation apps, and recommendation systems. It can also make mistakes, so people should check important results.
